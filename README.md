# Brittany Itinerary

Premium Brittany, France travel command center.

## Included
- Interactive 10-day Brittany route
- Day selector and itinerary detail panel
- Stylized route visualization
- Timeline mode
- Map mode
- Trip-health scoring
- JSON export
- Responsive mobile/desktop layout
- Premium editorial / glass / terrain visual language

## Run locally
```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Production roadmap
The current repository is the polished front-end foundation. The next production layer can add live maps, lodging/restaurant data, routing/ETAs, weather and tide intelligence, reservations, persistence/authentication, AI itinerary optimization, calendar sync, offline/PWA support, budgeting, sharing and PDF export.
